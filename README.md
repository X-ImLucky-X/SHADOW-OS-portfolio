# 💻 ShadowOS v2.0
**An Interactive Retro-Styled Developer Portfolio**

🌐 **Live Demo:** [https://shadow-os-portfolio.vercel.app/](https://shadow-os-portfolio.vercel.app/)

ShadowOS is a modern, high-fidelity developer portfolio styled as a retro, science-fiction operating system. Built from scratch with a custom window manager, it simulates a live OS environment directly in the browser.

---

## 🎯 Key Applications

- **Terminal.exe**: Interactive shell console powered by `xterm.js` supporting custom commands, tab completion, and hacking simulations.
- **AI_Assistant.bin**: A conversational chatbot styled as a Win95 hacker terminal. Driven by local regex knowledge routing to answer resume, projects, and contact queries.
- **About.me**: Developer bio featuring live GitHub commit analytics and a custom **LeetCode Telemetry** dashboard (Knight Tier stats).
- **Skills.sys**: Interactive skills radar charts and categorized keycap chips.
- **CyberSnake.exe**: Classic snake game integrated into a horizontal handheld retro console with LCD statistics.

---

## 🛠️ Tech Stack

- **Core**: React 18, TypeScript, Vite
- **Styling**: Tailwind CSS (custom retro double-bevel overrides)
- **State**: Zustand (global window state manager)
- **Charts**: Recharts & custom SVGs
- **Terminal**: xterm.js & xterm-addon-fit

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+)
- npm

### Installation
1. Clone the repository:
   ```bash
   git clone https://github.com/X-ImLucky-X/SHADOW-OS-portfolio.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Build for production:
   ```bash
   npm run build
   ```
